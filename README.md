# Caravan Logbook

Offline-first PWA for tracking caravan kilometres, trip legs, fuel/power, maintenance and campsites.
React + Vite + Tailwind + Lucide, vite-plugin-pwa. Data lives in IndexedDB (localStorage fallback) with JSON export/import.

```
npm install
npm run dev      # development
npm run build    # production build (generates service worker)
npm run preview  # serve the build
```
